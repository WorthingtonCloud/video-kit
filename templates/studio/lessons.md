# Lessons

What this studio has learned from its own videos: every note the human gave, turned into a rule, so the next video
doesn't need the same note. The skills read this file before anything else, every time; `profile.json` holds the
settled values (colors, voice, levels), this file holds the judgment.

How to add one: after each round of notes, one line per note, under the heading it belongs to, dated, with the why.
Keep the human's own words when they're vivid ("I'm falling asleep"). Merge a lesson that repeats an older one
instead of adding a second; delete one the human reverses.

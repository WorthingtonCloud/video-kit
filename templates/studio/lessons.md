# Lessons

What this studio has learned from its own videos: every note the human gave, turned into a rule, so the next video
doesn't need the same note. The skills read this file before anything else, every time; `profile.json` holds the
settled values (colors, voice, levels), this file holds the judgment.

How one gets here: only when the human says how far a note reaches. A note is one-off by default. When a pattern
shows, the agent words it as a rule (`vs review propose`), the human answers Every video, Every explainer/reel, This
video only or Ignore, and `vs review promote` writes the kept ones here, dated, under their heading, with a marker.
`vs review rules` lists them and `vs review forget` takes one out. Keep the human's own words when they're vivid
("I'm falling asleep"). You can edit this file by hand at any time: it's yours.
